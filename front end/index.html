Personal Portfolio

Web Design / Front-End Development

This website is the project I know best, because its subject is me. I designed and coded it myself, from the first sketch to the last line of CSS, so that it would reflect who I am: someone who works across code, film, photography, drawing and acting.

The home page is a collage of seven pieces, one for each side of my work. Choose one and the pieces fly apart to open that section. Every section then shares the same quiet, dark layout, so the work itself stays in front. The site is built with plain HTML, CSS and JavaScript, and it has its own vertical layout for phones and tablets.

This is how I approach every website: I take the time to understand the person behind it, and then design something original that could only belong to them.
